DATABASE
────────
Organized collection of DATA.


DBMS
────
Software that MANAGES
the database.

Responsibilities:

→ Read
→ Write
→ Update
→ Delete
→ Transactions
→ Concurrency
→ Security
→ Recovery
→ Indexing


RDBMS
─────
Relational DBMS.

Data organized into
RELATED TABLES.


Example:

CLIENT
   │
   │ client_id
   ↓
PARCEL
   │
   │ parcel_id
   ↓
PARCEL_EVENT


Remember:

Database = DATA

DBMS = SOFTWARE
          ↓
    manages DATA

RDBMS = DBMS
        based on
        RELATIONAL model
